How to read: chrF (0–100) character-level overlap with the reference — higher is closer; COMET (~0–1) neural metric, closer to human judgement (run with --comet); Keywords = key renderings correct (e.g. préfecture, 2e étage, avocado vs lawyer); Ambiguity = ambiguous words resolved correctly when context is given; Conf. reliability = Spearman correlation between model confidence and quality (−1…1, closer to 1 = “when it says it's sure, it really is”); Conf. no/with context = for the same ambiguous sentence, confidence should be lower without context. 95% CI / P(#1 better) come from a paired bootstrap: if P(#1 better) is below 95%, the two models are not clearly different on this test set. Green = best in column. References are drafts — use scores for relative comparison, not absolute quality.
